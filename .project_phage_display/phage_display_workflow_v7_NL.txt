设备间前后关系
阶段一：样品预处理（FANOUT-0，三轨并行）
实验从一个虚拟"开始节点"同时触发三条并行轨道：
- 轨道 A：Vantage-1 向阳性细胞管吸入 PBS，完成后由机械臂转移到离心机排队。
- 轨道 B：Vantage-2 向阴性细胞管吸入 PBS，同样由机械臂转移到离心机排队。
- 轨道 C：Vantage-3 向噬菌体管加入 BSA 封闭剂，由机械臂独立转入 Cytomat-2 预封闭 15 分钟（与 A/B 完全不共享设备）。
SYNC-0：配平离心汇合
A、B 两管同时进入离心机（两管配平，500xg 离心 5 分钟）。离心后机械臂将细胞板转入 Cytomat-1，封闭孵育 25 分钟。
SYNC-1：细胞封闭 + 噬菌体预封闭汇合
Cytomat-1（细胞封闭完成）和 Cytomat-2（噬菌体预封闭完成）两路同时结束后，机械臂取出并转到 Vantage-1 加 BSA 重悬，两条轨道在这里第一次合并。
阶段二至六：数据依赖串行主链
这段是生物学上必须串行的核心流程，设备依次接力：
Vantage-1 → 机械臂 → Cytomat-1（阴性孵育 45 min）→ 机械臂 → 离心机 → 机械臂 → Vantage-1（收上清）→ 机械臂 → Cytomat-1（阳性孵育 2h）→ 机械臂 → BioTek 洗板机（PBS 洗 3 次）→ 机械臂 → 离心机 → 机械臂 → Vantage-1（PBS 重悬）→ Vantage-1（加 PE 荧光抗体）→ 机械臂 → Cytomat-1（4°C 避光 30 min）→ 机械臂 → BioTek（洗去多余抗体）→ 机械臂 → Vantage-1（重悬转移流式管）
阶段五：FACS 分选
机械臂将流式管送入 FACSMelody，完成初始化 → 设门 → 分选 → 导出数据（四步串行，单仪器内部流程）。
阶段六：洗脱 + 感染扩增（最长瓶颈）
FACSMelody 完成后，机械臂→ 离心机 → 机械臂 → Vantage-1（酸洗脱 + 中和）→ 机械臂 → Cytomat-1（感染 E.coli 30 min → 37°C 扩增 1h → LB 过夜培养 16 小时，这是整个实验最长的等待段）→ 机械臂 → 离心机（6000xg 去菌体）→ 机械臂 → Tecan A200（0.22µm 无菌过滤）。
阶段七：克隆挑选（FANOUT-2，三轨并行）
机械臂将滤液送入 QPix 420（成像 → 选克隆 → 挑至 96 孔板），再由机械臂载入 Cytomat-1 过夜培养（又一个 16h 等待）。
培养完成后，从 Cytomat-1 同时触发三条并行验证轨道：
- 验证轨 A：机械臂 → FACSMelody（流式检测各克隆荧光强度）
- 验证轨 B：机械臂 → BioTek（ELISA 洗板检测结合活性）
- 验证轨 C：机械臂 → QiaCube（质粒提取）→ 机械臂 → SeqStudio（Sanger 测序，需 2h）
SYNC-2：三路验证结果汇合
FACS / ELISA / 测序三路完成后，Vantage-1 汇合结果，筛选阳性克隆，触发最终的蛋白验证分叉。
阶段八：并行蛋白验证（FANOUT-3，两轨并行）
克隆组 A 和克隆组 B 完全对称，同时进行：
- 克隆组 A：机械臂 → BioXp-1（基因组装 → 转化）→ 机械臂 → 离心机 → 机械臂 → AKTA-1（亲和层析纯化）
- 克隆组 B：机械臂 → BioXp-2（基因组装 → 转化）→ 机械臂 → 离心机 → 机械臂 → AKTA-2（亲和层析纯化）
两台 BioXp 和两台 AKTA 互不干扰，完全并行。
SYNC-3：最终汇合 → Biacore
AKTA-1 和 AKTA-2 都完成纯化后，Vantage-1 汇合两组蛋白，机械臂转入 Biacore 8K+（8 通道同时测定 KD → 特异性交叉验证），实验结束。

---
关键瓶颈：两段 Cytomat-1 过夜培养（各 16h）决定了 47h 总时长，增加再多台设备也无法缩短。
