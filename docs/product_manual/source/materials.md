# 物料管理

:::{admonition} 阅读角色
- **业务负责人**：确认物料名称、规格、容量、放置规则、条码和现场状态。
- **开发人员**：实现物料模板、放置位约束、启动图实例和工作流资源合同。
- **验收人员**：核对实物兼容性、位置关系、数量变化、搬运和异常恢复。
:::

物料管理维护实验室中容器、样品、仓库和库位的逻辑事实。工作流会用这些事实寻找输入、申请资源锁，并在物理转运成功后提交新位置。

## 进入页面

在 Uni-Lab OS 左侧点击“物料”。页面由层级树、详情区和操作区组成。你可以按名称、UUID、模板或条码查找对象。

## 查看物料和库位

1. 在左侧层级树选择物料、设备或仓库。
2. 在详情区核对 UUID、条码、模板、父级、子级和当前位置。
3. 展开“拥有的站点”，查看站点是否空闲、允许哪些模板以及当前占用者。
4. 如果对象被任务使用，先到“任务”页确认其预留、锁和运行状态。

“当前位置”是调度和库存使用的权威逻辑位置。它不会自动证明现场确实存在该物体；真机操作仍需核对传感器和现场状态。

## 创建物料

1. 点击“新建物料”。
2. 选择资源模板。模板决定对象的类型、字段、容量和可放置站点。
3. 填写名称和唯一条码；按模板补充必填字段。
4. 如需同时入库，选择一个兼容且空闲的初始站点。
5. 提交后，在树和详情中核对新对象与位置。

创建与初始放置是一个原子操作：如果目标站点不再空闲或数据不合法，系统不会留下只创建未放置的半成品记录。

## 装载、移动和卸载

### 装载或移动

1. 选择需要移动的物料。
2. 点击位置操作，选择候选站点。
3. 核对目标所属设备或仓库、模板兼容性和空闲状态。
4. 提交并等待页面刷新。
5. 同时核对源站点已释放、目标站点已占用。

候选列表会排除结构件、已占用站点和模板不兼容站点。位置更新携带期望修订号；如遇冲突，刷新页面后重新判断，不要盲目重试。

### 卸载

点击“卸载”会把物料移到“未分配”状态，不会删除物料本身，也不会清除历史。只有当现场物体已经从当前库位移走且没有运行任务依赖它时，才应执行卸载。

## 条码核对与导出

- 在搜索框输入条码可以快速核对容器身份。
- 导出会生成当前物料清单的 CSV，适合盘点和离线复核。
- 导出文件只是快照；之后的任务、移动或试剂消耗不会回写该文件。

## 与任务的关系

提交工作流时，`ResourceSlot` 和材料来源会解析到具体物料及站点。任务可能为它们创建：

- 设备、物料或工位的执行锁；
- 试剂数量预留；
- 物料转移待提交记录。

物理转运成功后应由工作流或 Host 唯一一次提交物料位置。不要在动作执行中途手工移动同一物料，否则调度器的锁、现场状态和库存台账可能失去一致性。
