## 背景与数据可得性结论

提供了两份数据，对 3 个目标输出的支撑情况如下：

- **RNA浓度检测** —— XML 里**没有**，只存在于 xlsx 报告的「RNA浓度检测」sheet（源自 Nanodrop `.ned`）。→ 只能从 xlsx 提取，无法从 XML 计算。
- **qPCR板排布及扩增曲线** —— **可从 XML 完整计算**。XML 含每孔逐采集点的 `Fluor/Temp/Time`，且已确认：每孔约 202 个采集点，**第 1–45 点为扩增（恒温 ~60°C，每循环一次）**，**第 46 点起为熔解曲线（温度爬升）**；孔位映射来自 `<analyses>/<AnalysisSample>/Position`（Sample N ↔ A1..P24）。
- **qPCR统计与分析（ΔCT/ΔΔCT/2^-ΔΔCT/Mean/SD）** —— XML 里 384 孔 `CrossingPoint`(Cq) **全空、全阴性**，且只有 "Sample N" 与孔位、**无内参/目的基因与分组标注**，因此**无法从该 XML 算出 Cq 和统计**。CT 值只能取自 xlsx；拿到 CT 后，ΔCT/ΔΔCT/2^-ΔΔCT/Mean/SD 的**数学计算我可以做**。

## 方案

- **语言/依赖**：Python 3，使用标准库 `xml.etree.ElementTree`、`csv`、`statistics`；读 xlsx 用 `openpyxl`（环境已安装）。
- **位置**：按你的要求放在 `unilabos/script/`（当前仓库无此目录，会新建；仓库现有的 `script/` 为 Python 脚本目录可作备选）。
- **入口**：单个程序 `unilabos/script/qpcr_report_extract.py`，命令行参数：`--xml <原始xml>`、`--xlsx <报告xlsx，可选>`、`--out-dir <输出目录，默认当前目录>`。一次运行生成 3 个 CSV。

### 输出 1：`rna_concentration.csv`（RNA浓度检测）
- 来源：解析 xlsx「RNA浓度检测」sheet。
- 列：`Sample Name, Nucleic Acid(ng/uL), A260/A280, A260/A230`，并附带电子数据存储位置一行注释。
- 未提供 xlsx 时：仅输出表头模板。
- 标注：**该表无法从 XML 计算**。

### 输出 2：`qpcr_plate_and_curves.csv`（qPCR板排布及扩增曲线，全部来自 XML）
- 解析 `<Acquisitions>` 与 `<AnalysisSample>` 建立 `样本号→孔位` 映射。
- **板排布**：16×24 网格（A–P × 1–24），单元格填该孔的样本号（空孔留空）。
- **扩增曲线**：每个有数据的孔一行，列为 `Position, SampleNo, Cycle_1..Cycle_45` 的荧光值（取第 1–45 采集点）。
- 熔解曲线（第 46 点起）默认不导出，可选加 `--with-melt` 另存 `melting_curve.csv`。

### 输出 3：`qpcr_stats_analysis.csv`（qPCR统计与分析）
- CT 来源：xlsx「qPCR统计与分析」sheet（按行标签区分 空白对照组/样本，及内参基因/目的基因两列、每组 2 个重复）。
- **我负责计算**：`ΔCT = CT(目的) − CT(内参)`；`Ave.Blank = 空白对照 ΔCT 均值`；`ΔΔCT = ΔCT − Ave.Blank`；`2^(-ΔΔCT)`；每组 `Mean`、`SD`（样本标准差 n−1，已用报告数值校验：0.9461/1.057 → SD 0.0784 ✓）。
- 输出列：`Sample, 内参基因CT, 目的基因CT, ΔCT, Ave.Blank, ΔΔCT, 2^(-ΔΔCT), Mean, SD`。
- 标注：**Cq 无法从该 XML 计算**（全阴性），故 CT 依赖 xlsx；若仅给 XML，则该表 CT 列输出 `Undetermined`，统计列留空。
